All Phase 2 CTAs, for reference

Click a CTA below to open its custom form and modal window. Adding ?topic= and the topic name to a button's link loads the form with that topic pre-selected.

Additional notes

All handoff files, including the production code, the copy doc and the developer guide, are on GitHub: phase 2 CTA modals folder · README (developer guide)

Topic values

Use these after ?topic= in a button's link, for example /contact-us/?topic=frame. They match the internal values of the HubSpot property "CTA discussion topic" (cta_discussion_topic).

Topic valueDropdown labelOpens on
generalGeneral questionSend a message
projectAn L&D projectSend a message
maturity-assessmentStrategy Maturity AssessmentSend a message
alignment-sprintAlignment Sprint coachingSend a message
learning-strategyLearning strategy (SOAP or Strategy Workshop)Send a message
ai-enablementAI EnablementSend a message
measurementLearning MeasurementSend a message
frameFRAME™ / FOAP callBook a time
recommendationHelp choosing where to startBook a time
otherSomething elseDropdown only, no button

What a button needs in Elementor

A class and a link, set in the button's Link and Advanced settings. With JavaScript off, the link still goes to the contact page.
